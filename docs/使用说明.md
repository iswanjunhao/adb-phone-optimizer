# 使用说明（详细版）

本文档在 README 基础上，补充各功能的使用细节与排错。

## 一、环境准备

1. **Python**：3.8 及以上（仅用标准库，无需 pip install）。
2. **adb**：
   - 推荐放入 PATH：
     - Ubuntu/Debian：`sudo apt install android-tools-adb`
     - macOS：`brew install android-platform-tools`
     - Windows：下载 [platform-tools](https://developer.android.com/tools/release-notes) 并加入 PATH
   - 或运行仓库根目录 `./get_adb.sh` 自动下载到 `./platform-tools/`。
3. **设备**：开启「开发者选项 → USB 调试」。多设备同时连，工具会自动列出并支持切换。

## 二、启动

```bash
./run.sh        # Linux / macOS
run.bat         # Windows
```

启动后访问 `http://127.0.0.1:8787`。日志打印在终端，出现 `Serving on ...` 即成功。

## 三、各标签页用法

### 📊 设备概览
展示型号、品牌、Android 版本、电量、内存、存储。下方「一键优化」可清理后台进程、释放内存（不影响前台应用）。

### 🧹 包名管理器
- **搜索**：输入包名或中文名（如「浏览器」「小米视频」）。
- **筛选**：系统/用户/可卸载/谨慎/关键/未知。
- **操作**：
  - 卸载：`-k --user 0` 保留数据卸载，可恢复。
  - 禁用：停用预装（关键包需二次确认）。
  - 恢复：「已卸载·可恢复」筛选项里一键 `install-existing` 恢复。
- **安全库**：`packages_db.json` 标记了 130+ 常用包的风险等级，红色「关键·勿动」包会强制确认。

### 🎛️ 系统调优
开关与表单改动即时生效，部分项会自动回滚并提示。包含广告追踪、深色、字体、DPI、刷新率、后台限制、系统更新、性能模式、绝对音量、私有 DNS。

### 📁 文件管理
浏览 `/sdcard`、新建文件夹、把手机文件拉到电脑并下载、把电脑文件上传推送到手机。

### 📡 无线调试
- 状态面板显示 USB / TCP 已连设备。
- 点「开启无线」执行 `adb tcpip 5555`，填 IP+端口「连接」后即可拔线。
- 支持「断开」。

### 📈 监控诊断
- 电池温度：电量/温度/电压/健康 + 传感器温度。
- 实时性能：CPU/内存/上下行，原生曲线每 2 秒刷新（零依赖图表）。
- 权限审计：列出用户应用的危险权限（定位/相机/麦克风等）。
- 健康报告：一键汇总型号/电池/存储/应用/已做调优，可打印。

### 🤖 模拟输入 / 🕹️ 自动化进阶
- 模拟输入：点击坐标、滑动、输入文本、按键、截图/录屏。
- 宏：手动编排步骤序列，存为宏反复回放。
- 定时任务：每天定时 / 间隔分钟自动执行调优或宏。
- 预设：内置「省电/游戏/护眼/纯净隐私」4 套，一键套用、可导出 JSON、可保存自定义。

## 四、墨水屏注意事项

详见 README「墨水屏特别说明」。一句话：管理类功能全可用，显示类调优（深色/刷新率）多无效但会安全跳过。

## 五、排错

- **找不到设备**：确认 USB 调试已开、线正常、弹出框点了允许；`adb devices` 应列出设备。
- **卸载失败**：见 README 常见问题，多数改用「禁用」。
- **无线连不上**：手机与电脑需同局域网；首次建议先用 USB 执行一次 `tcpip 5555` 再拔线连接。

## 六、数据安全

- 不收集任何数据，全部在本机运行。
- 文件管理仅在你主动操作时在电脑↔手机间传输。
