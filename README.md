# ADB 设备优化助手（ADB Device Optimizer）

一个**零依赖、纯本地**的网页 GUI 工具：通过 ADB 优化你的安卓设备——卸载/禁用预装广告软件、调系统隐藏设置、传文件、监控电池与性能、自动化点击滑动、一键预设方案。

支持**任意开启「USB 调试」的安卓设备**：手机（小米 15 Pro / HyperOS / MIUI 等）、**墨水屏（e-ink）**、平板等。多设备同时连接时可一键切换。

> 全部操作**仅作用于「当前用户」**，绝大多数可随时恢复；对关键系统组件有强制二次确认，可放心使用。

## 🚀 快速开始

### 1. 手机/设备准备
- 打开「开发者选项 → USB 调试」（墨水屏等也需开启 USB 调试）。
- 用数据线连接电脑，在弹出的「允许 USB 调试」上点允许。

### 2. 准备 adb（二选一）
- **方式 A（推荐）**：把 `adb` 放进系统 `PATH`（如 `apt install android-tools-adb` / `brew install android-platform-tools`）。
- **方式 B（零配置）**：运行仓库自带脚本自动下载 platform-tools：
  ```bash
  ./get_adb.sh
  ```

### 3. 启动工具
```bash
# Linux / macOS
./run.sh
# Windows
run.bat
```
然后用浏览器打开 **http://127.0.0.1:8787** 即可。

> 🪟 **Windows 用户**请额外阅读 [`docs/Windows使用说明.md`](./docs/Windows使用说明.md)（含环境配置、命令、以及用 **GitHub 个人访问令牌（PAT）** 推送项目的完整步骤）。

> 后端是 Python 标准库实现，**无需 pip 安装任何依赖**（Python 3.8+ 即可）。

## 📟 墨水屏（e-ink）特别说明

ADB 是通用协议，墨水屏连接后 appar 会像手机一样出现在「选择设备」面板中，可随时切换。

- ✅ **完全可用**：包名管理（卸载/禁用/恢复）、文件管理、权限审计、电池%、无线 ADB、自动化（点击/滑动/输入/截图）、宏、预设（部分步骤）。
- ⚠️ **可能无效/异常**（命令会安全跳过，不会崩溃）：
  - 强制深色模式（单色屏无意义）
  - 刷新率上限（墨水屏无高刷）
  - 字体缩放 / DPI（可用但需谨慎，调太细会看不清）
  - 录屏（多半失败，截图可用）
  - 电池温度（可能无 thermal 传感器，电量%仍正常）

套用「游戏性能」等预设时，不适用的步骤会自动标红跳过，其余正常执行。

## 🔒 安全说明

- 所有卸载/禁用只对**当前用户**生效（`--user 0`），可随时恢复，**不会影响系统完整性**。
- 内置安全库标记「关键·勿动」的系统核心包（如 `com.android.systemui`、`com.miui.home`）在卸载/禁用时**强制二次确认**，避免误操作。
- 所有危险操作均有二次确认弹窗。
- 卸载失败会给出**中文原因**（如「系统/厂商保护，无法卸载，建议改用禁用」），不再笼统报「操作失败」。

## ❓ 常见问题

**Q：提示「卸载失败」？**
A：多为系统/厂商保护了该应用，`pm` 报错在输出里且退出码为 0。本工具已能识别并提示真实原因——这类应用请用同行的「禁用」按钮停用（可恢复），这是无 Root 优化预装最稳的办法。

**Q：连了手机和墨水屏两台设备？**
A：页面顶部「选择设备」面板可随时在两台间切换，无需拔线。

**Q：需要 Root 吗？**
A：不需要。全部功能基于 ADB 的 `--user 0` 与 `settings` 等公开接口。
